EHD · Ion Wind · Venturi · Experiment Analysis

알파프로젝트 EHD 벤츄리 시뮬레이터

축대칭 전기장 계산, 경험적 공간전하 모델, 벤츄리 유동 근사, 실험 CSV 기록, 실측–시뮬레이션 비교 분석을 한 흐름으로 묶은 공개 연구 도구입니다.

Google Colab에서 실행 GitHub 저장소 보기
PythonNumPySciPyMatplotlibipywidgetsPandas

무엇을 하는 프로젝트인가

EHD 추진 장치의 형상과 전극 조건을 바꿔가며 상대적인 경향을 빠르게 비교하고, 실제 실험 데이터가 쌓이면 그 결과와 시뮬레이션 값을 같은 CSV에서 비교할 수 있도록 만든 실험 지원용 플랫폼입니다.

Simulation

축대칭 전위·전기장 해석

전극 전압과 위치를 바꾸며 축대칭 Laplace 해를 계산하고 전기장 크기 분포를 시각화합니다.

EHD Model

공간전하 및 체적력 근사

경험적 공간전하 분포와 Coulomb 체적력 f = ρₑE를 사용해 상대적인 EHD 구동 경향을 계산합니다.

Experiment

실험 데이터 기록

에미터·콜렉터 정보, 전극 간격, 실측 전압·전류·풍속과 시뮬레이션 결과를 CSV에 함께 저장합니다.

현재 구현된 기능

벤츄리 형상 조절

입구·목·출구 반지름과 throat 위치를 UI에서 바꾸며 형상 효과를 비교합니다.

3전극 전압 설정

방전, 유도, 가속 전극 전압과 가속 전극 위치·길이를 조절할 수 있습니다.

실측/시뮬 비교

실측 풍속과 시뮬레이션 출구 유속, 전압·전류와 풍속 관계를 자동 그래프로 확인합니다.

1 mm 간격 분석

전극 간격을 1 mm 단위로 그룹화해 평균 풍속, 표준편차, 평균 전류·전압·오차율을 계산합니다.

형상별 통계

에미터/콜렉터 조합별 평균 풍속과 표준편차를 비교할 수 있습니다.

최적 관측 조건 선택

현재 CSV 안에서 최대 풍속, 최대 속도 증가량, 최소 오차 등 목적별 최고 관측 조건을 찾아줍니다.

사용 흐름

코드를 따로 내려받지 않아도 Colab에서 바로 실행할 수 있습니다.

1
Colab 실행

위의 버튼으로 공개 노트북을 엽니다.

2
시뮬 조건 설정

형상과 전극 전압을 정하고 RECALCULATE를 실행합니다.

3
실험값 저장

전압·전류·풍속과 전극 정보를 입력해 CSV에 누적합니다.

4
통계 분석

비교 그래프, 간격별 통계, 형상별 성능과 최적 관측 조건을 확인합니다.

모델 해석 시 주의

현재 시뮬레이터는 완전 결합 코로나 방전·전하수송·Navier–Stokes 해석이 아닙니다. 공간전하는 경험적 분포이며 유동 응답도 단순화된 근사 모델입니다. 따라서 출력값은 절대 추력 예측값보다는 형상·전압 조건 간 상대 비교와 실험 설계 보조에 적합합니다.
